
# Short Summary of Python

## What is Python?
- a **programming language** which was developed as a **scripting language**
- **free available** across all major operating systems
- enables **object-oriented** and **functional** programming.
- a **general-purpose** language
- *package manager*: **pip**

## What is Python commonly used for?
- **website** and **software development**,
- **task automation**, 
- **data analysis** and **machine learning**, 
- **data visualization**

## How Python works:
- sourcecode **doesn't** need to be **compiled**
- uses **indentation** to define code blocks

```python
print("Hello World")
```
