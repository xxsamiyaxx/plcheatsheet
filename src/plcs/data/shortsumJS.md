# Short summary of JavaScript

## What is JavaScript
- **J**ava**S**cript = JS
- a **scripting** or **programming language** -> make websites interactive and dynamic
- a multi-paradigm language
- *package manager*: **npm**
- *file extension*: **.js**

## Usages of JavaScript
-  **Virtual reality (VR) & artificial intelligence (AI)** applications.
- Adding **interactive** behavior to **web pages**
- **Web** and **mobile** development
- **Browser-based game development**

## How JavaScript works
- interpreted language -> **not** require a **compilation**
- **weakly typed** language -> variables are not bound to a fixed data type

## Code example
```javascript
console.log('Hello World');
```
