# Short summary of Bash Scripting

## What is Bash
- **Bash** = **B**ourne **A**gain **S**hell
- a **scripting language**
- a **command-line interface (CLI) shell**
- used to **interact** with **Unix-based operating systems** like Linux and macOS

## What is a Bash script
- a **plain text file** which contains **commands** which will be step by step executed by the Bash shell
- *Common file extension*: **.sh**

## Usages of Bash scripts
- **Automation** of **repetitive** work
- **System Administration**
- **Handling complex environments**

## Making a Bash script executable
```bash
# 1. Make script executable
chmod +x bash_script.sh

# 2. Starting the script
./bash_script.sh
```

## Code Example
```bash
#!/bin/bash
echo "Hello World"
```
