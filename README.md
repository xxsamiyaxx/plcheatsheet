# plcheatsheet

## About this project
**plcheatsheet** is a **command line tool** which is written in Python. With this tool you can **quickly** look up
several programming languages, more precisely you can search for the main syntax of a programming language.

## Included programming languages
- **Python** → its basic syntax + several libraries (e. g. os, argparse, qiskit)
- **C#** → its basic syntax + usage with unity
- **C++** → its basic syntax
- **JavaScript** → basic syntax
- **SQL**
